I build end to end in TypeScript, React, NestJS and Java/Spring Boot, and I only call something done after it has been tested, measured and reviewed for security. That is where the problem the happy path hides shows up.

Today at **Stech** I fix vulnerabilities in financial systems, I delivered a whole education platform, and I build tools with AI agents. In them, the model does not review its own code, authorization comes before the prompt, and every run has a time limit and a cost measured in tokens.

Before development I looked for root causes in market intelligence at **Itaú** and worked SLA-bound support at **Sintel**, where an incident has a deadline. I also taught at **Cebrac**: a twelve-class track from zero to Power BI and an AI workshop for fifteen students.
